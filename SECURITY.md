# Security Policy & Coordinated Vulnerability Disclosure

## Scope
This policy covers `sovret-crypto` (`RCENC` v1, `RCSTR` v1, X-Wing hybrid KEM, OPAQUE/Argon2id flows, Mullvad-style Strict IDs, SKL, WASM deterministic builds, and `sovret-verify`).

## Reporting a Vulnerability
Please report suspected security or cryptographic flaws privately via GitHub Security Advisories on this repository (do not open public issues for unpatched vulnerabilities).

- Acknowledgement target: within 48 hours.
- Status updates: at least every 7 days until resolved.

## Safe Harbor
We authorize good-faith security research against this public codebase and our designated staging/test targets. We will not pursue legal action against researchers who follow responsible disclosure, avoid accessing/modifying other users' data, and avoid destructive denial-of-service testing.
